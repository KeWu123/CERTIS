# Post-matrix all-mask count-allocation experiment

Written 2026-10-16 after inspection of the complete original 1,376 records,
the 32 matched point-degree controls, and 64 stronger exact controls. This
is an exploratory follow-up, not a held-out or retrospectively registered
confirmation. No original arm, case or result is replaced.

Candidate: replace the 65 global degree-prefix masks by the exact maximum
certified number of discarded unknown identities, at each fixed cache.
Use the proved side-count reduction and min-plus resource allocation.
The recurrence is classical. Its all-mask/Boolean reduction is the claim.
It minimizes snapshot retained identity count, not expected adaptive cost.
Later masks contain the actual old discarded identity sets. Every key's
signed support is retained. The optimized four-frontier arithmetic is
checked against the original 36-pair integer kernel on every returned plan.

Eligibility is structural and label-blind: every identity occurs in at
most one key, complete unit-incidence blocks, disjoint left/right. Run all
16 single-key-mode targets from the original matrix. All 16 multi-key-mode
targets are excluded because they reuse identities; the new exact planner
does not claim that relaxation. Save every eligible and excluded case ID.

Audited cells: every eligible target, seeds 101/202/303, side audit budgets
125 and 500: 96 complete executions. Matched point-only cells: every
eligible target, zero random labels and no helper, deterministic seed101:
16 executions. One exact all-mask feedback method; no outcome-selected
variants. Total 112 new executions, all must finish or retain failures.

Evidence, failure budget, input versions, per-side SRS, hypergeometric
intervals, unit request prices, fixed initial degree execution order,
batch size128, exact dynamic possible-partner pruning, charged cache and
SQL output contract match the existing degree direct arm. All sources and
input hashes are frozen before execution; no oracle labels reach the
planner except through Oracle.acquire. Intervals are fixed at the initial
draw. A contradictory domain freezes the last mask and is recorded.

For every complete record independently check acquired labels/tokens,
bag subset and counts, observed recall, per-region coverage, and same-start
request containment using original-parquet SQL after the policy finishes.
Always materialize the actual returned SQL bag; no count-only shortcut.

Compare requests and token counts against the original degree direct arm
at every matched seed/budget and against the point-degree supplement.
Compare initial effective discard counts (unknown IDs only), not base-mask
cardinality that includes cached rescued positives. All-mask initial
counts must weakly exceed every matched prefix's effective discard count;
this is a theorem check, not a guarantee of lower complete adaptive cost.
Report win/tie/loss, pooled cost, loss and computation; retain regressions.
Timing is local Python/SQL time; tapes do not establish live inference
latency. Reused fixed targets and exact controls are dependent observations.

Before this protocol, synthetic Boolean/planner checks and synthetic
N<=5000 computation measurements were run; no external execution of this
all-mask method was used to choose its reported cases or parameters.
